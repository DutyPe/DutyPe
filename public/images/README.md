# Open Graph Images for Job Sharing

This directory contains Open Graph (OG) images used when job links are shared on social media platforms like WhatsApp, Facebook, and Twitter.

## Required Images

### 1. og-job-default.png
- **Size:** 1200x630 pixels
- **Purpose:** Default image shown when a job is shared but no job-specific image exists
- **Content:** DutyPe logo, tagline "Find Your Perfect Job", gradient background
- **Format:** PNG or JPEG

### 2. og-jobs.png
- **Size:** 1200x630 pixels
- **Purpose:** Generic image for the jobs landing page
- **Content:** DutyPe branding, "Join 100,000+ workers finding jobs"
- **Format:** PNG or JPEG

## Design Guidelines

- Use DutyPe brand colors: Primary Blue (#3B82F6), Purple (#667eea)
- Include DutyPe logo prominently
- Keep text minimal and readable
- Use high contrast for better visibility on all platforms
- Test on WhatsApp, Facebook, and Twitter to ensure proper display

## Tools for Creating Images

- Canva (recommended for quick creation)
- Figma (for professional designs)
- Adobe Photoshop/Illustrator

## Testing

After creating images, test them using:
- Facebook Sharing Debugger: https://developers.facebook.com/tools/debug/
- Twitter Card Validator: https://cards-dev.twitter.com/validator
- LinkedIn Post Inspector: https://www.linkedin.com/post-inspector/
