## 🏆 UNIQUE FEATURES ONLY DUTYPE CAN OWN

These features don't exist in ANY competitor. Build these to create an unbeatable moat:

### 1. **Video Job Description (KILLER FEATURE)**
```
Problem: Text is easy to fake. "Data Entry Job ₹30k" is a lie.
Solution: Employer MUST record 15-second video to post job.

Example: "Hi, I am Suresh from Laxmi Bakery in Ameerpet. 
         I need a helper who knows how to bake puffs. 
         Salary ₹12,000. Come meet me."

Why It Wins: A scammer in a dark room CANNOT do this.
             A real shop owner CAN.
             Trust +100%
```

### 2. **Community Vouch System (Indian Culture Digitized)**
```
Problem: In India, we hire based on "Do you know him?"
Solution: When worker signs up, ask "Who knows you in this colony?"

Flow:
1. Worker adds reference (local Pan Shop owner / contact on app)
2. Reference confirms: "Yes, I know Ramesh. He's reliable."
3. Worker gets "Verified Local" badge

Why It Wins: Digitizes the Indian reference system.
             No other app does this.
```

### 3. **Hyper-Local Radar Map (Uber for Jobs)**
```
Problem: Static map pins are boring. No urgency.
Solution: Dark-mode map with pulsing animated dots.

Visual:
🔴 Red (fast pulse) = IMMEDIATE (Today)
🟠 Orange (medium pulse) = URGENT (This Week)  
🟢 Green (slow pulse) = NORMAL
🔵 Blue (no pulse) = FILLED

Why It Wins: Makes job discovery feel ALIVE.
             Workers can plan routes efficiently.
             Maids can take 5 jobs in same building.
```

### 4. **Audio-First Interface (TTS)**
```
Problem: 450M blue-collar workers, many semi-literate.
Solution: Speaker icon next to every job title.

Flow:
1. Worker taps 🔊 icon
2. App speaks: "Cook job. Salary 12,000 rupees per month. 
               Location Ameerpet. Contact Suresh."

Why It Wins: No other job app does this.
             Accessibility = massive market.
```

### 5. **SafePay Escrow (Worker Protection)**
```
Problem: Worker does job, employer doesn't pay.
Solution: Employer deposits payment BEFORE job starts.

Flow:
1. Employer posts job → Deposits ₹500 in escrow
2. Worker completes job → Shows completion code
3. Employer confirms → Money released to worker
4. Dispute? → DutyPe mediates

Why It Wins: Workers feel PROTECTED.
             Employers who don't pay get banned.
```


### 6. **No-Data-Entry Firewall (Scam Killer)**
```
Problem: 90% of job scams are "Work from home" / "Data entry" / "Online typing"
Solution: Auto-block these keywords INSTANTLY.

Banned Keywords:
- Online, SMS, Investment, Part-time WFH
- Laptop required, PDF conversion
- Work from home, Data entry
- Typing job, Form filling

Action: Block post → Show warning: 
        "DutyPe is for PHYSICAL location jobs only."

Why It Wins: Eliminates 90% of scams instantly.
             No "Earn ₹50k from home" garbage.
```

### 7. **Market Rate Suggestions (Fair Wage Engine)**
```
Problem: Employers lowball. Workers don't know market rates.
Solution: App suggests local market rate when posting.

Example:
Employer selects: Cook (Full-time)
App shows: "💡 Suggested rate for Cook in Hyderabad: ₹12,000/month"
           "Range: ₹8,000 - ₹18,000"

If too low: Warning "This is below market rate. You may not get applicants."
If too high: Warning "This is above market rate. Are you sure?"

Why It Wins: Fair wages for workers.
             No exploitation. No unrealistic expectations.
```

### 8. **Background Safe-Check Display**
```
Problem: Users scared to let strangers into their homes.
Solution: Show verification status BEFORE hiring.

Display:
┌─────────────────────────────────────┐
│  🛡️ BACKGROUND SAFE-CHECK          │
├─────────────────────────────────────┤
│  [PHOTO]  Ramesh Kumar              │
│           ✅ Aadhaar Verified       │
│           📍 12 jobs in Ameerpet    │
│           ⭐ 4.8 (8 reviews nearby) │
│           🏠 Trusted for home entry │
└─────────────────────────────────────┘

Why It Wins: Users feel SAFE.
             "12 jobs in YOUR area" is powerful social proof.
```

### 9. **Standby Bench (No-Show Killer)**
```
Problem: Caterer needs 10 waiters, fears only 6 will come.
Solution: Book 10 "Active" + 3 "Standby" workers.

Flow:
1. Employer books 10 Active + 3 Standby
2. Active workers must turn on "On the Way" GPS by deadline
3. If Active doesn't confirm → Auto-Fire → Auto-Hire Standby
4. Standby gets notification: "You're now Active! Report to venue."

Why It Wins: 100% attendance guarantee.
             No other app does this.
```

### 10. **Employer Behavior Score**
```
Problem: Bad employers abuse workers, don't pay, lie about job.
Solution: Track employer behavior, show score to workers.

Metrics:
- Payment on time: 95%
- Job description accuracy: 4.2/5
- Worker reviews: 4.5/5
- Disputes: 2 in 50 jobs

Display: "⚠️ This employer has 2 payment disputes in last 3 months"

Why It Wins: Protects workers from bad employers.
             Bad employers get fewer applicants.
```

// functions/src/fraudDetection.ts

interface FraudCheckResult {
  score: number;
  signals: string[];
  action: 'APPROVE' | 'REVIEW' | 'REJECT';
}

export const checkJobForFraud = functions.firestore
  .document('jobs/{jobId}')
  .onCreate(async (snap, context) => {
    const job = snap.data();
    const userId = job.employerId;
    
    let fraudScore = 0;
    const signals: string[] = [];
    
    // CHECK 1: Velocity (jobs posted in last hour)
    const recentJobs = await db.collection('jobs')
      .where('employerId', '==', userId)
      .where('postedAt', '>', Date.now() - 3600000)
      .get();
    
    if (recentJobs.size > 5) {
      fraudScore += 30;
      signals.push('VELOCITY_HIGH');
    }
    
    // CHECK 2: Duplicate content
    const similarJobs = await db.collection('jobs')
      .where('description', '==', job.description)
      .where('employerId', '!=', userId)
      .limit(1)
      .get();
    
    if (!similarJobs.empty) {
      fraudScore += 40;
      signals.push('DUPLICATE_CONTENT');
    }
    
    // CHECK 3: Blacklist check
    const phoneBlacklist = await db.collection('blacklists')
      .where('type', '==', 'PHONE')
      .where('value', '==', job.contactNumber)
      .limit(1)
      .get();
    
    if (!phoneBlacklist.empty) {
      fraudScore += 100;
      signals.push('BLACKLISTED_PHONE');
    }
    
    // CHECK 4: Suspicious timing (midnight posts)
    const hour = new Date(job.postedAt).getHours();
    if (hour >= 0 && hour <= 5) {
      fraudScore += 10;
      signals.push('SUSPICIOUS_TIMING');
    }
    
    // CHECK 5: New account posting high-value job
    const user = await db.collection('users').doc(userId).get();
    const accountAge = Date.now() - user.data()?.createdAt;
    const isNewAccount = accountAge < 24 * 60 * 60 * 1000; // < 24 hours
    
    if (isNewAccount && parseInt(job.payAmount) > 20000) {
      fraudScore += 25;
      signals.push('NEW_ACCOUNT_HIGH_VALUE');
    }
    
    // DETERMINE ACTION
    let action: 'APPROVE' | 'REVIEW' | 'REJECT';
    if (fraudScore <= 30) {
      action = 'APPROVE';
    } else if (fraudScore <= 60) {
      action = 'REVIEW';
      // Add to moderation queue
      await db.collection('moderation_queue').add({
        jobId: context.params.jobId,
        fraudScore,
        signals,
        status: 'PENDING',
        createdAt: admin.firestore.FieldValue.serverTimestamp()
      });
    } else {
      action = 'REJECT';
      // Auto-hide job
      await snap.ref.update({ isActive: false, rejectionReason: 'FRAUD_DETECTED' });
      // Increment user fraud score
      await incrementUserFraudScore(userId, fraudScore, signals);
    }
    
    // Log the check
    await db.collection('fraud_logs').add({
      jobId: context.params.jobId,
      userId,
      fraudScore,
      signals,
      action,
      timestamp: admin.firestore.FieldValue.serverTimestamp()
    });
    
    return { score: fraudScore, signals, action };
  });

// services/LivenessDetectionService.kt

/**
 * Liveness Detection to prevent photo-of-photo attacks
 * Uses ML Kit Face Detection with liveness challenges
 */
class LivenessDetectionService @Inject constructor() {
    
    private val faceDetector = FaceDetection.getClient(
        FaceDetectorOptions.Builder()
            .setPerformanceMode(FaceDetectorOptions.PERFORMANCE_MODE_ACCURATE)
            .setLandmarkMode(FaceDetectorOptions.LANDMARK_MODE_ALL)
            .setClassificationMode(FaceDetectorOptions.CLASSIFICATION_MODE_ALL)
            .enableTracking()
            .build()
    )
    
    data class LivenessChallenge(
        val type: ChallengeType,
        val instruction: String,
        val completed: Boolean = false
    )
    
    enum class ChallengeType {
        BLINK,          // "Blink your eyes"
        SMILE,          // "Smile please"
        TURN_LEFT,      // "Turn your head left"
        TURN_RIGHT,     // "Turn your head right"
        NOD             // "Nod your head"
    }
    
    /**
     * Generate random liveness challenges
     */
    fun generateChallenges(): List<LivenessChallenge> {
        val allChallenges = listOf(
            LivenessChallenge(ChallengeType.BLINK, "Blink your eyes twice"),
            LivenessChallenge(ChallengeType.SMILE, "Give a big smile"),
            LivenessChallenge(ChallengeType.TURN_LEFT, "Turn your head to the left"),
            LivenessChallenge(ChallengeType.TURN_RIGHT, "Turn your head to the right")
        )
        return allChallenges.shuffled().take(3) // Pick 3 random challenges
    }
    
    /**
     * Verify challenge completion from face detection result
     */
    fun verifyChallengeCompletion(
        face: Face,
        challenge: LivenessChallenge
    ): Boolean {
        return when (challenge.type) {
            ChallengeType.BLINK -> {
                val leftEyeOpen = face.leftEyeOpenProbability ?: 1f
                val rightEyeOpen = face.rightEyeOpenProbability ?: 1f
                // Eyes closed = blink detected
                leftEyeOpen < 0.3f && rightEyeOpen < 0.3f
            }
            ChallengeType.SMILE -> {
                val smileProbability = face.smilingProbability ?: 0f
                smileProbability > 0.7f
            }
            ChallengeType.TURN_LEFT -> {
                val headRotation = face.headEulerAngleY
                headRotation < -20f // Head turned left
            }
            ChallengeType.TURN_RIGHT -> {
                val headRotation = face.headEulerAngleY
                headRotation > 20f // Head turned right
            }
            ChallengeType.NOD -> {
                val headTilt = face.headEulerAngleX
                headTilt < -10f || headTilt > 10f // Head nodded
            }
        }
    }
    
    /**
     * Anti-spoofing checks
     */
    fun detectSpoofingAttempt(face: Face, imageMetadata: ImageMetadata): SpoofingResult {
        val signals = mutableListOf<String>()
        var spoofScore = 0
        
        // Check 1: Face too flat (photo of photo)
        val faceContour = face.getContour(FaceContour.FACE)
        if (faceContour != null) {
            val depthVariance = calculateDepthVariance(faceContour.points)
            if (depthVariance < 0.1f) {
                spoofScore += 30
                signals.add("FLAT_FACE_DETECTED")
            }
        }
        
        // Check 2: Unnatural lighting
        if (imageMetadata.brightness < 0.2f || imageMetadata.brightness > 0.9f) {
            spoofScore += 20
            signals.add("UNNATURAL_LIGHTING")
        }
        
        // Check 3: Screen reflection (moire pattern)
        if (detectMoirePattern(imageMetadata.rawPixels)) {
            spoofScore += 40
            signals.add("SCREEN_REFLECTION_DETECTED")
        }
        
        // Check 4: Face boundary check (cut-off face = printed photo)
        if (face.boundingBox.left < 10 || face.boundingBox.top < 10) {
            spoofScore += 25
            signals.add("FACE_BOUNDARY_SUSPICIOUS")
        }
        
        return SpoofingResult(
            isSpoof = spoofScore > 50,
            confidence = spoofScore,
            signals = signals
        )
    }
}

// services/VideoJobService.kt

/**
 * Video Job Description Service
 * Ensures employers are REAL by requiring video proof
 */
class VideoJobService @Inject constructor(
    private val storage: FirebaseStorage,
    private val mlKit: MLKitService
) {
    
    companion object {
        const val MIN_VIDEO_DURATION_SECONDS = 10
        const val MAX_VIDEO_DURATION_SECONDS = 30
        const val MAX_VIDEO_SIZE_MB = 20
    }
    
    data class VideoValidationResult(
        val isValid: Boolean,
        val errorMessage: String? = null,
        val detectedFaces: Int = 0,
        val hasAudio: Boolean = false,
        val duration: Int = 0,
        val fraudSignals: List<String> = emptyList()
    )
    
    /**
     * Validate video before upload
     */
    suspend fun validateVideo(videoUri: Uri, context: Context): VideoValidationResult {
        val signals = mutableListOf<String>()
        
        // CHECK 1: Duration
        val duration = getVideoDuration(videoUri, context)
        if (duration < MIN_VIDEO_DURATION_SECONDS) {
            return VideoValidationResult(
                isValid = false,
                errorMessage = "Video must be at least $MIN_VIDEO_DURATION_SECONDS seconds"
            )
        }
        if (duration > MAX_VIDEO_DURATION_SECONDS) {
            return VideoValidationResult(
                isValid = false,
                errorMessage = "Video must be less than $MAX_VIDEO_DURATION_SECONDS seconds"
            )
        }
        
        // CHECK 2: File size
        val sizeInMB = getFileSize(videoUri, context) / (1024 * 1024)
        if (sizeInMB > MAX_VIDEO_SIZE_MB) {
            return VideoValidationResult(
                isValid = false,
                errorMessage = "Video must be less than ${MAX_VIDEO_SIZE_MB}MB"
            )
        }
        
        // CHECK 3: Has audio (employer must speak)
        val hasAudio = checkHasAudio(videoUri, context)
        if (!hasAudio) {
            signals.add("NO_AUDIO")
            // Warning but don't block
        }
        
        // CHECK 4: Face detection (at least one face visible)
        val frames = extractKeyFrames(videoUri, context, count = 5)
        var totalFacesDetected = 0
        for (frame in frames) {
            val faces = mlKit.detectFaces(frame)
            totalFacesDetected += faces.size
        }
        
        if (totalFacesDetected == 0) {
            signals.add("NO_FACE_DETECTED")
            return VideoValidationResult(
                isValid = false,
                errorMessage = "Please show your face in the video",
                fraudSignals = signals
            )
        }
        
        // CHECK 5: Not a screen recording (detect UI elements)
        val isScreenRecording = detectScreenRecording(frames)
        if (isScreenRecording) {
            signals.add("SCREEN_RECORDING_DETECTED")
            return VideoValidationResult(
                isValid = false,
                errorMessage = "Screen recordings are not allowed. Please record a real video.",
                fraudSignals = signals
            )
        }
        
        // CHECK 6: Location metadata (if available)
        val hasLocationMetadata = checkLocationMetadata(videoUri, context)
        if (!hasLocationMetadata) {
            signals.add("NO_LOCATION_METADATA")
            // Warning but don't block
        }
        
        return VideoValidationResult(
            isValid = true,
            detectedFaces = totalFacesDetected,
            hasAudio = hasAudio,
            duration = duration,
            fraudSignals = signals
        )
    }
    
    /**
     * Extract text from video frames (for shop board detection)
     */
    suspend fun extractTextFromVideo(videoUri: Uri, context: Context): List<String> {
        val frames = extractKeyFrames(videoUri, context, count = 10)
        val allText = mutableSetOf<String>()
        
        for (frame in frames) {
            val textBlocks = mlKit.recognizeText(frame)
            allText.addAll(textBlocks)
        }
        
        return allText.toList()
    }
    
    /**
     * Verify shop name appears in video
     */
    suspend fun verifyShopNameInVideo(
        videoUri: Uri,
        expectedShopName: String,
        context: Context
    ): Boolean {
        val extractedText = extractTextFromVideo(videoUri, context)
        val normalizedExpected = expectedShopName.lowercase().replace(" ", "")
        
        for (text in extractedText) {
            val normalizedText = text.lowercase().replace(" ", "")
            // Fuzzy match (at least 70% similarity)
            if (calculateSimilarity(normalizedExpected, normalizedText) > 0.7) {
                return true
            }
        }
        
        return false
    }
}
